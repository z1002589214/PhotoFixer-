📌 软件简介
PhotoFixer 是一款用于批量修复照片和视频元数据的 Windows 工具。它能从文件名中提取日期时间，写入文件内部的元数据，让苹果相册、Lightroom 等软件能正确识别文件的拍摄时间。

核心功能
✅ 从文件名自动提取日期时间

✅ 支持 JPEG / PNG / GIF / HEIC / MP4 / MOV / M4V / 3GP 格式

✅ 自动检测并修正文件后缀错误（如 .jpg 伪装成 .png）

✅ 多线程并发处理，速度快

✅ 支持使用文件创建日期作为备选

✅ 自动标记星级（5星 / 4星 / 3星）

✅ 无需安装 Python，直接运行

🚀 使用方法
方式一：双击运行（最常用）
双击 PhotoFixer.exe

根据提示输入照片文件夹路径（支持拖拽）

按提示设置时间范围（如 2015 ~ 2026）

选择是否使用创建日期作为备选

查看预览清单，确认后输入 y 开始处理

等待完成

方式二：拖拽文件夹到 exe 图标
将照片文件夹拖拽到 PhotoFixer.exe 图标上

松开鼠标，程序自动开始处理

方式三：命令行带参数运行
bash
PhotoFixer.exe "D:\RJCC\百度网盘\2"
适合批量处理多个文件夹时使用。

❓ 常见问题
Q1: 提示 找不到 exiftool.exe
确保 exiftool.exe 和 PhotoFixer.exe 在同一个文件夹

Q2: 某些文件的日期没有被提取
该文件的年份不在你设定的时间范围内

文件名格式不在支持列表中

文件名是纯数字编号（如 47435304），且年份超出范围

Q3: 软件卡住了怎么办？
大文件处理需要时间，请耐心等待

如果超过 2 分钟无响应，按 Ctrl+C 终止，然后重新运行

可以尝试减少 MAX_WORKERS 参数（需要重新打包）

Q4: 怎么验证修改是否成功？
在软件处理完成后，用看图软件查看文件的属性

或在苹果相册中查看照片的拍摄时间

也可以用 ExifTool 命令行验证：exiftool -DateTimeOriginal -Rating 文件.jpg

Q5: 处理前需要备份吗？
强烈建议备份！ 元数据写入后无法撤销

⚠️ 重要提示
🔴 操作不可逆
元数据写入后无法"撤销"，请务必先备份整个文件夹再运行软件。

🟡 先小范围测试
先用一个包含少量测试文件（5~10 张）的文件夹试运行，确认效果后再处理整个相册。

🟢 杀毒软件误报
部分杀毒软件可能对打包的 .exe 文件误报。这是 PyInstaller 打包的正常现象，添加信任即可。
